# DEDEM Mekatronik resmi renkleri

Kaynak: `Dedem-Mekatronik-Kurumsal-Kimlik-Rehberi.pdf`, sayfa 02 "Logotype Renk".

| Ad       | HEX       | RGB           | CMYK         | Uygulamada kullanım |
|----------|-----------|---------------|--------------|---------------------|
| BLACK    | `#1D1D1B` | 29, 29, 27    | 0, 0, 0, 100 | Üst çubuk, splash, ikon zemini, Excel başlık zemini |
| RED      | `#E30613` | 227, 6, 19    | 0, 100, 100, 0 | Butonlar, seçili sekme, vurgu çizgisi |
| WHITE    | `#FFFFFF` | 255, 255, 255 | 0, 0, 0, 0   | Zemin, siyah/kırmızı üzerindeki yazı |
| SILVER   | `#706F6F` | 112, 111, 111 | 0, 1, 1, 56  | İkincil yazı (beyazda 5.0:1) |
| GRAY     | `#9D9D9C` | 157, 157, 156 | 0, 0, 1, 38  | Kenarlıklar (yazı için kontrastı yetersiz) |
| SILVER C | `#C6C6C6` | 198, 198, 198 | 0, 0, 0, 22  | Ayırıcılar |

Kurumsal yazı tipi: **Roboto** (sayfa 03–05). Android'in sistem yazı tipi olduğu için uygulamaya ayrıca gömülmedi.

Okutma geri bildirim renkleri (başarı yeşili, uyarı turuncusu, hata kırmızısı) kurumsal renklerden bağımsızdır;
bkz. `lib/ui/theme/colors.dart`.
